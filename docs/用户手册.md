# 用户手册

## 第一次启动

双击 `伴行Agent.exe`。若从开发终端/脚本环境启动，使用 `启动伴行.bat`（会清掉 `ELECTRON_RUN_AS_NODE`，避免 exe 被当作纯 Node 运行）。应用会自动创建：

- `data/config.json`：配置
- `data/memory/*.jsonl`：五层记忆
- `data/chat/`：桌面与 QQ 会话
- `data/logs/`：运行日志
- `data/.electron/`：Chromium 缓存（固定在此，不写 AppData）

如果双击无反应，先运行 **`检查环境-只读.bat`**，再查看 `data/logs/`。

## 接入模型

1. 左侧「模型接入」。
2. 主模型：
   - 协议：OpenAI 兼容（DeepSeek、OpenAI、多数中转、Ollama、LM Studio）或 Anthropic Messages。
   - API URL：如 `https://api.deepseek.com/v1`。
   - 模型名：不再手输。填写 URL 和 Key 后，应用请求接口的 `/models`，自动填充「可用模型」下拉框；也可以点「自动探测模型」刷新。URL 或 Key 改变后会自动重探。
   - Key：只存在本机 `data/config.json`，界面只显示掩码。
3. 点「保存」，再点「保存并测试」。会发送一张测试图（数字 42），通过后徽章显示「多模态已验证」。
   - 官方 DeepSeek V4.1 Flash 的模型 ID 是 `deepseek-flash`，下拉选项会带「支持图片」。如果选中 `deepseek-v4-pro`，它是纯文本模型，视觉测试不会通过。
   - 只支持纯文本的模型仍可用于对话，但无法直接看图；建议再接入一个视觉辅助模型。
   - 如果 `deepseek-flash` 仍显示未通过，模型卡片下方会显示完整 `visionDetail`（HTTP 错误、空回答或未识别测试图），可据此判断是模型、端点还是图片格式问题。
4. 辅助模型：打开开关，填一个支持图片输入的模型。主模型通过 `ask_helper` 调用它；它不能自行操作 QQ/手机。

### 本地模型

- Ollama：`http://127.0.0.1:11434/v1`，Key 留空；点「自动探测模型」或「发现本机 Ollama」。
- LM Studio：`http://127.0.0.1:1234/v1`。
- 支持 OpenAI `/chat/completions` 的任意网关均可。

## 对话

- Enter 发送，Shift+Enter 换行。
- 回形针添加图片；文件夹按钮添加音频/其他文件。附件会先写入多模态记忆，再进入当前轮。
- 后台是 `工作 / 陪伴 / 学习` 三条连续维度，归一化为 100%。**AI 看不到百分比**，但可以读取定性取向，并通过 `weight_tune` 做有冷却、有限力度的小幅修正。
- **强信号**：工作很高时，一句“我累了”会把陪伴迅速抬到工作之上；其他维度保留基线，不会归零。0.70 是归一化前的目标强度，不是最终界面百分比；归一化后会被其他维度的基线摊薄。
- **时间衰减**：没有新信号时，各维度按自己的半衰期指数回到基线；工作约 20 分钟半衰期，陪伴更长，学习居中。基线非零，代表能力仍然在场。
- **冷却/迟滞**：强事件后短时间内反向触发需要更高置信度，避免反复横跳。
- **话题锚点**：工作/学习信号会留下锚点；说“继续刚才那个”且话题足够相似时，会恢复当时的权重配置。
- **5 小时转存**：超过约 5 小时没有工作信号，进行中的工作压缩为工作日志，工作维度回到基线，不会归零；后续可从工作日志和锚点继续。
- 「清空」只清桌面会话消息，不清记忆。

## 记忆

- **知识库**：只有带来源的条目才较可靠。可手动写入、编辑、重新核验、归档。重新核验会走完整闭环，旧版本保留在 revisions。超过时效的条目在回答前会先自动复核；记忆页也提供“复核过时 N”批量操作。
- **关系记忆**：用户偏好、情感事件、边界。检索优先级最高；可手动添加、编辑修正或移除。
- **手动修正**：关系记忆、进行中/已归档工作日志、多模态说明与标签都可以编辑；记错的内容修正后立即参与检索，并标记 editedBy=user。
- **工作日志**：出现工作任务后自动跟踪；闲置超过阈值自动归档。也可在卡片上立即归档。
- **状态轨迹**：每次发言的触发词与三线前后占比，以及时间衰减、锚点恢复和 AI 微调。
- **多模态**：图片可点开查看，图片/音频的说明可以手动修正；手机截图在其中。桌面截图只在“手机与电脑”页面临时查看，不写入多模态记忆。
- **反思**：权重积累后自动生成；可在成长轨迹手动生成。
- 如果侧边栏有数字但当前标签为空，点「刷新」或切到有内容的层；新版会在进入记忆时自动落到第一个有内容的层。

## 印象与亲近度

- 「印象」页收录群聊和私聊里见过的所有人，以 **QQ 号**为稳定身份，昵称与 QQ 同时显示。
- **亲近度 0-100**：根据对话中的正向/负向信号缓慢变化，也可以手动编辑。
- **印象**：由模型根据最近发言动态刷新，也可以手动编辑；右上角可立即刷新。
- 每个人的卡片有「手动修改」开关。开启后，AI 不再自动改变其亲近度和印象；关闭后恢复动态。
- 如果同一个 QQ 号换了昵称，人物记录会保留旧昵称到“曾用昵称”，并自动刷新该 QQ 在关系记忆中的昵称；群聊和私聊的记忆不会串到别人身上。
- 删除人物档案只删除这份印象账本，不删除已有关系记忆。

## 角色自迭代

- AI 可通过 `persona_self_update` 或自动校准修改知识线/情感线；不再需要用户手动触发。
- 需要至少 3 条稳定核心证据；情绪事件不能单独改人设。
- 保留 24 小时情绪冷静期、AI 修改冷却、7 天次数上限、锁定与回滚。
- 启动迁移会把旧版“3 天/72 小时”门槛更新为“0 天/24 小时”，只改护栏参数，不改已有角色线。

## 戳一戳 / 并发消息 / 引用

- OneBot `notice_type=notify, sub_type=poke` 会进入 Agent，用短句回应。
- 同一 QQ 会话在 `batchWindowMs`（默认 900ms）内的多条消息会先缓存，按“@、回复、是否提到你、是否在问问题、是否戳一戳”打分，只处理最相关的一条；其他内容作为上下文，不逐条回复。
- 用户回复机器人或 @ 机器人时，QQ 回复会带 `reply` 引用段；普通闲聊不强制引用。
- 回复长度按任务复杂度选择：普通 QQ 闲聊 1–3 句，明确要求分析/展开时才允许较长回复。

## 多模态插件插槽

模型接入页新增 5 个插槽：

| 插槽 | 用途 | 默认 |
|---|---|---|
| vision | 识图 / 画面理解 | helper |
| ocr | 图片文字提取 | helper |
| audio | 语音转写 | helper |
| document | 文档 / 网页解析 | primary |
| imagegen | 图像生成 | helper |

插槽可选 primary / helper / custom / off。点每个插槽的「配置」可以单独填写 API URL、协议、模型名和 Key；`custom` 可直接接本地 Ollama/LM Studio。子模型只做事，不直接回复用户；主模型通过 `multimodal_task` 拿结果并统一作答。语音和图像生成需要对应端点真正支持，否则会明确报未接入。

## 音乐与清唱

侧边栏「音乐」是可视化调试窗口：

- **耳朵**：读取网易云 PC 版当前播放、进度、当前歌词。需要网易云以 `--remote-debugging-port=9222` 启动；读不到会显示具体原因。
- **点歌 / 歌词**：搜索网易云歌曲、读取歌词、控制播放（play/pause/next/previous）。
- **清唱**：输入歌名或一句话，使用 Windows SAPI 生成 WAV；页面可直接播放。AI 在 QQ 会话中调用 `music_sing` 时会通过 OneBot `record` 段发送语音。
- 这是本地朗读式清唱，不会冒充真人歌声；需要真实歌声时可在多模态插槽接入音频/歌声模型。
- 音频文件保存在 `data/music/`，不会自动删除。

## 日记

- 侧边栏「日记」；`data/diary/diary.jsonl` 本地存储。
- AI 可用 `diary_write` 写日记，`diary_read` 回看；也可点「让 AI 写今天」。
- 用户可手写、查看、删除；日记不作为知识事实，不会自动发到 QQ。

## 闲时自学习

- 白名单内安静达到 **60 分钟**（默认）后，后台会自己选一个安全、公开、与长期兴趣相关的问题，走完整学习闭环。
- 门控：白名单活动时间、夜间静默、180 分钟冷却、每天最多 4 次。非白名单消息不会重置这个空闲计时。
- 这些数值都可以在「闲时学习」页直接修改并保存：空闲门槛、检查间隔、两次学习间隔、每天最多、静默开始/结束。
- 设置页「搜索与爬虫」可多选搜索引擎（Bing / DuckDuckGo / Wikipedia / 百度 / 搜狗 / SearXNG）、填 SearXNG、指定 Edge/Chrome 路径；无头浏览器用于 JS 动态页面。视频页面可保存元数据/缩略图，非流媒体可下载到多模态记忆。
- 自学习不限定固定方向，可以自由发散；但选题先通过四项审查：
  1. 是否在安全主题范围内
  2. 是否包含隐私（QQ、电话、住址、身份证、邮箱、账号等）
  3. 是否触发政治/色情/暴力/高风险内容
  4. 是否空泛、古怪、无法形成具体问题
- 任一项不通过就回退到预设安全方向，不会硬发。
- 搜索结果、抓取正文和知识写入还会再做内容过滤。
- 分类规则：人类情感/关系主题只写关系记忆（`emotional_material`），用于让 AI 更有人情味；AI/技术类知识写知识库，用于让 AI 更聪明。每条自学习只进一个地方，避免重复双写。
- 不会主动发 QQ 消息。
- 侧边栏「闲时学习」展示：
  - 每条自学习轨迹、来源、置信度、结果
  - 最终进入知识库的正式条目或候选
  - 从自学习写入的 `emotional_material` 情感材料
- 自学习内容涉及情感/关系主题时，会写入关系记忆，作为情感线的辅助证据；人设仍需要稳定核心证据，不能只靠自学习材料改写。

## 人格演化与情感记忆

- 角色页的「情感线」不再由 AI 直接改写，而是由第一人称情感记忆逐层形成。
- 聊天中遇到值得留下的感受，会先写一条 `emotional_note` / 自动情感记忆；标签、情绪、强度反复出现后才进入稳定情感线。
- 角色页可以看到最近的情感记忆、强度、来源，以及本次修订证据。
- 主要时间门槛已移除：不再限制情感线修改次数或冷却；一条第一人称情感记忆留存后即可直接进入稳定人格层。
- 知识线仍用于让 AI 更会求真；情感线只用于陪伴语气与关系方式。
- 收到的 QQ 表情包会单独存到 `data/memory/stickers/`；普通图片、截图仍存 `data/memory/media/`。AI 发表情时优先用已保存的表情，内置表情只作兜底。
- 日记支持自主写入：距上篇超过 6 小时且当前对话达到一定轮次时，AI 会自己写一篇；不需要用户点按钮。

完整的 System Prompt 模块、Python 报错拦截伪代码、记忆拼接策略见 [人格演化框架](人格演化框架.md)。

## 手机与电脑

- 手机：ADB 随应用放在 `tools/platform-tools`；默认「自动」模式会扫描 5555/16384/62001/21503 等常见模拟器端口并自动 `adb connect`，兼容 MuMu / LDPlayer / Nox / BlueStacks / MEmu 等。点「自动检测并连接」即可；识别到设备后可直接点「用这台」。未连接时会提示开启 USB 调试或模拟器 ADB。
- 路径输入框旁边都有「浏览」，直接打开 Windows 资源管理器选择文件夹/文件；不再要求手输完整路径。
- 电脑：需要显式开启「电脑操作权限」；可读取屏幕尺寸/窗口列表/截图，鼠标、键盘、启动和 Shell 各自有独立子权限。未开启时不会执行任何操作。
- 首次接入测试建议顺序：手机页点「自动检测并连接」→ 选择设备 → 读屏/截图 → 电脑页开启权限 → 读取窗口/截图 → 再测试点击与输入。
- 所有页面表单在内部刷新/切换时保留未保存输入；切换页面再回来也不会把正在填写的路径、坐标、文本直接清空。

## 闲时自主活动

- 「闲时学习」页新增「闲时自主活动」：空闲达到门槛后，她可以自己拿起手机/电脑，玩 B 站、视频、游戏或探索应用，不需要用户先发指令。
- 可分别开启手机/电脑，限制动作步数、活动间隔和是否允许下载 APK；默认不碰用户文件。
- 每次活动写入 `data/autonomy/sessions.jsonl`，在闲时学习页显示最近记录。
- 失败不会只说“我再试一次”：对话与自主活动都增加了继续执行/明确阻塞的续跑逻辑。

## 音乐播放与 RVC

- 音乐页「一键探测 / 接入」会检查网易云 CDP 端口，找得到客户端时尝试带 `--remote-debugging-port=9222` 启动。
- 点歌先走客户端；客户端注入失败时回退到公开直链，真的在本机播放，并把音频显示在页面。
- 清唱默认 Windows SAPI；音乐页新增外部 RVC 配置：Python、RVC 目录、`.pth`、index、变调。RVC 转换失败会保留 SAPI，不会丢语音。
- RVC 模型需要在 RVC WebUI 中自行训练；本应用负责调用 `infer_cli.py`，不伪造自训练结果。

## 搜索与网页

- 搜索会并行尝试 Bing、DuckDuckGo、Wikipedia；Bing RSS 不可用时自动抓取 HTML 结果。
- 抓取正文会去掉脚本、导航、页脚和表单，优先读取 `article/main`，不再只截取导航栏。
- 你直接粘贴 `https://...` 或 `www....` 时，伴行会先打开网页并把正文放入上下文；打不开会说明原因，不会反问“HTTP 是什么”。
- 搜索/抓取工具需要模型支持 Function Calling；模型接入页会实际探测并写入能力标记。旧配置中 DeepSeek Flash 的 `tools=false` 会自动按官方能力启用。

## 表情包

- 内置 8 张本地表情包（好耶、抱抱、无语、晚安、加油、嘿嘿、让我想想、OK）。
- 用户发来的 QQ `mface` 会进入多模态记忆，标记为 `sticker` / `表情包`；普通图片如果说明里带“表情包”也会被识别。
- AI 先用 `sticker_search` 搜索已保存的表情（拿到 `mediaId`），再用 `send_sticker` 发送；也支持 `media:<id>`。
- 内置表情和已保存表情走同一条发送链路；不会再出现“多模态通路不通”。
- 桌面会话不会伪装成 QQ 表情。

## Hermes 插件

- 原名 `harmes` 是拼写错误，已更正为 **Hermes**。
- 启动时只迁移插件 ID（`harmes → hermes`），不会重置模型 API、对话、记忆、人物印象或角色设定。
- 工具：`hermes_recall`、`hermes_remember`、`hermes_reflect`、`hermes_growth`。
- 情感事件与稳定偏好/边界分开存储；`hermes_remember` 可显式指定 `memory_class=emotional|stable`。

## 角色设定

- **知识线**：她怎么求真、怎么处理来源和不确定性。
- **情感线**：她怎么接住情绪、怎么陪伴、怎么保持边界。
- 身份（名字/角色/关系）和安全边界固定，不能由 AI 修改。
- 你可以点「编辑两条线」直接改；也可以点「让 AI 根据记忆校准」。AI 改角色必须引用真实记忆 ID，并会把 before/after、理由、证据写入 `data/persona/revisions.jsonl`。
- **角色稳定性护栏**：
  - AI 至少需要 3 条真实证据、跨至少 3 天；至少 1 条知识/偏好/边界等稳定核心。
  - 情绪事件不能单独改写人设，且情绪事件数量不能多于稳定证据。
  - 最近有强烈情绪事件时，情感线会进入至少 24 小时冷静期。
  - AI 修改有 72 小时冷却，7 天最多 2 次。
  - 可以关闭「允许 AI 自学习修改角色线」；关闭后只有用户能改。
  - 支持「回滚上一版」。
  - 只会使用主人/全局记忆做校准，群聊中其他人的印象不会改变 AI 的底层人设。
- 在聊天中 AI 也可以调用 `persona_update`，但同样受上述护栏约束。

## QQ / OneBot 桥接

### A. 手动 OneBot（推荐，SnowLuma 连不上时用）

任何兼容 OneBot v11 的 QQ 网关都可以：

1. 在网关里开启 OneBot WebSocket 与 HTTP API，记下地址与 Token。NapCat、Lagrange、LLOneBot、go-cqhttp、SnowLuma 都适用。
2. 伴行「QQ 桥接」→ 连接方式选「手动 OneBot v11」。
3. 填 WS（如 `ws://127.0.0.1:3001`）、HTTP（如 `http://127.0.0.1:3000`）、WS Token、HTTP Token（可以不同）。
4. 填主人 QQ，保存 → 测试 OneBot → 启动监听。
5. 状态显示已连接、绑定 QQ 即成功。

### B. 自动发现 SnowLuma

1. 工作目录已放置 SnowLuma（默认 `integrations/SnowLuma`）；关闭应用后手动运行 `launcher.bat`，按官方 WebUI 完成 EULA、扫码登录。
2. SnowLuma WebUI 打开 OneBot HTTP API 与 WebSocket 服务，记下端口/token。
3. 伴行「QQ 桥接」连接方式选「自动发现 SnowLuma」，填主人 QQ、白名单，保存并启动。
4. 若自动发现失败，切手动模式填同样的地址和 Token。

### 群聊 / 私聊活跃度

QQ 页面上方有独立的“互动活跃度”卡片，群聊和私聊各有一组手动/AI 动态模式和滑杆。

- **手动模式**：滑杆由你控制。
- **AI 动态模式**：后台根据群聊热度、当前陪伴/工作权重自动调节滑杆；直接拖动滑杆会自动切回手动。
- **群聊活跃度**：0-100，控制非 @ 普通消息被接住的概率；@ 永远优先。`群回复冷却` 防止连续刷屏。
- **私聊主动活跃度**：0-100，0 表示不主动打扰。安静达到阈值后，按概率自主选题、查资料（可选先看手机），再回 QQ 开新话题；`最短主动间隔` 防止频繁打扰。
- 主动话题的“查资料/看手机”是两个独立开关；看手机需要手机已连接且开启手机控制。点“立即主动试一次”可手动验证。
- 主动消息会标记为“主动”，仍受白名单与发送审计约束。

### QQ 主对话

打开「把 QQ 主人私聊接入主对话」后：

- 你在 QQ 里给机器人发私聊，消息会出现在应用的「对话」页，AI 的回复自动发回 QQ。
- 你在应用「对话」页发消息，AI 的回答也会回写主人 QQ（不会把你的原话伪装成机器人消息发出）。
- 记忆、权重、角色线共用同一套；QQ 未连接时应用内仍可本地聊天。

安全：

- 空白名单时默认不放行。不要轻易打开「空白名单全部放行」。
- 黑名单优先于白名单和主人。
- 发送前会做敏感信息脱敏；QQ 发送工具必须由用户明确要求才会被主模型调用。
- SnowLuma 是第三方 Hook/QQ 互操作项目；账号风险与 EULA 由你自行承担。伴行不自动扫码、不自动同意 EULA、不修改 QQ 进程。
- 两篇文章的精读与抓取方式见 `docs/articles/README.md`；文章对应仓库的 OneBot transport 作为手动连接的协议依据。

## 手机

### 真机
1. 手机开发者选项 → USB 调试 → 连接电脑 → 手机上允许。
2. 「手机与电脑」选择真机 → 刷新。
3. 点截图、读取界面；坐标输入后点击。
4. 中文输入需要安装 ADBKeyboard 并启用；否则只能输入 ASCII。

### 模拟器
1. 安装 Android Studio Emulator，创建 AVD；或先手动启动第三方模拟器。
2. 切到「模拟器」→ 刷新 → 选择设备。
3. 有 AVD 时可在页面直接启动（端口 5554）。
4. 第三方模拟器通常已开 ADB 调试；若没有，可在模拟器设置里开启。

### 独立 MCP
`mcp/phone/mcp-phone.js` 是标准 MCP stdio 服务；便携 exe 使用 `mcp/phone/mcp-phone.bundle.mjs`。环境变量：`BANXING_HOME`、`ADB_PATH`、`PHONE_MODE=real|emulator`、`PHONE_SERIAL`、`PHONE_ALLOW_SHELL=1`。

## 用量

侧边栏「用量」类似模型开放平台的用量面板：

- **今日总 tokens / 输入 / 输出**：每次模型调用按 API 返回的 usage 累计；如果服务没有返回 usage，会标记为估算。
- **上下文缓存命中率**：DeepSeek/兼容服务返回 `prompt_cache_hit_tokens` 等字段时，按命中 token / 输入 token 计算；不支持时显示“—”。
- **记忆命中率**：本轮至少召回一层记忆（知识/关系/工作日志/多模态）的调用占比。
- **当前上下文**：最近一次对话调用的输入 token / 上下文窗口比例。
- **对话消耗**：桌面主对话、QQ 私聊、QQ 群分别聚合。
- **最近调用**：模型、入口、输入/输出、缓存命中、延迟。
- 「重置统计」只清用量，不删除聊天和记忆。

export function activate(api) {

## 只读检查

- 根目录：`检查环境-只读.bat` + 同目录的 `check-readonly.ps1`（BAT 只做 ASCII 启动，PowerShell 执行只读检查）
- 内置副本：`scripts/check-readonly.bat` / `scripts/check-readonly.ps1`（打包进 exe 的 resources，首次运行复制到根目录）
- UI：设置与检查 → 运行只读检查；默认启动后 8 秒也会静默检查一次
- 环境变量干扰：如从开发终端启动，请用 `启动伴行.bat`，它会清掉 `ELECTRON_RUN_AS_NODE`

检查项：关键文件、配置摘要（不显示 Key）、记忆计数、本机端口、两份脚本哈希、SnowLuma 存在性。它不测试登录/密钥/QQ 收发。

## 常见问题

**启动后一直停在加载页**  
运行只读检查；看 `data/logs/app-*.log`；确认 exe 同目录可写。

**模型测试失败**  
检查 URL 是否含 `/v1`、协议是否选对、网络/代理、Key，以及该端点是否实现 `/models`。某些中转只实现聊天接口、不实现模型列表，此时无法自动探测；模型名不再支持手输。某些中转不支持多模态，文字通过即可使用对话。若选择官方 DeepSeek V4.1 Flash，请确认下拉框选中的是带「支持图片」的 `deepseek-flash`，而不是 `deepseek-v4-pro`。

**QQ 显示已连接但收不到消息**  
检查 SnowLuma 的 Hook 是否仍在线；OneBot 心跳 `status.good`；WS token 与 HTTP token 可能不同（伴行会自动发现）。必要时在 SnowLuma 里重新登录账号并重启监听。

**手机无设备**  
`adb devices` 是否有 `unauthorized`；在手机确认授权。模拟器需要开启 ADB 调试。可执行 `tools/platform-tools/adb.exe devices -l` 查看。

**中文输入失败**  
安装 ADBKeyboard，并在手机输入法里启用；或用英文/数字测试。

**想关闭电脑/手机工具**  
模型接入 → 权限，关闭对应开关；电脑页的授权也会即时失效。
