# 第三方组件与许可

## 本项目

伴行 Agent 自有源码：MIT。你可以修改、分发；请保留安全边界与只读检查脚本。

## qq-bridge

- 路径：`vendor/qq-bridge/`
- 上游：<https://github.com/Derpyu520/qq-bridge>
- 版本：`0.2.0-r4`（`package.json`）
- 许可：MIT（`vendor/qq-bridge/LICENSE`）
- 用途：保留完整架构与文档；运行时直接复用 `src/snowluma-conn.js` 的 SnowLuma 端点/token 自动发现逻辑。其主桥接进程未被直接运行，因为上游面向 DSH Web API。

## SnowLuma

- 路径：`integrations/SnowLuma/`（官方 Windows 完整版 v1.14.22，用户要求下载到工作目录）
- 上游：<https://github.com/SnowLuma/SnowLuma> · 文档 <https://snowluma.github.io/zh/>
- 许可：源码可见非商业许可 + EULA 1.1；包含专有原生组件。
- 边界：
  - **没有**打包进 `伴行Agent.exe`，也没有复制进安装包。
  - 不做自动安装、自动扫码、自动同意 EULA。
  - 其 EULA §5.4 要求：将其并入第三方安装包/Docker 镜像或通过自动化脚本部署，须事先取得书面授权。因此伴行只探测与连接，由用户手动启动并完成登录。
  - 使用可能违反 QQ 平台条款并导致账号限制；风险由使用者承担。
  - 商业使用或再分发前，请向 SnowLumaDevs 取得书面授权。

## SnowLuma SDK / MCP 包

- `@snowluma/sdk`、`@snowluma/mcp` 通过 npm 安装，版本 ^1.14.22，许可随包（SEE LICENSE IN LICENSE）。
- 其 ESM 发布包存在相对导入缺少 `.js` 的问题；`scripts/patch-snowluma-sdk.mjs` 在安装后做机械修补（同样做法见 qq-bridge）。

## MCP TypeScript SDK

- `@modelcontextprotocol/sdk`，MIT；用于内置 MCP 客户端与独立 phone/computer MCP server。

## Electron / Electron Builder

- Electron：MIT；Electron Builder：MIT。
- 打包产物包含 Chromium 与 Node 运行时。

## Android Platform Tools

- `tools/platform-tools/` 来自 Google Android SDK Platform Tools 37.0.1。
- 使用受 Android SDK 许可约束；请阅读随附 `NOTICE.txt`。

## 其他前端依赖

- 无前端框架；UI 为原生 HTML/CSS/JS。
- `esbuild`（MIT，仅构建期）。
- `ws`（MIT，仅开发自检）。

## ai-companion-kit

- 路径：`vendor/ai-companion-kit/`
- 上游：<https://github.com/pinganbbOvO/ai-companion-kit>
- 许可：MIT（随附 LICENSE）
- 用途：两篇文章对应的开源工具，提供 OneBot v11 transport（NapCat/Lagrange/LLOneBot/SnowLuma 等）、角色卡、按人记忆、phone-mcp 的参考实现。本项目保留完整源码用于对照；实际运行时使用自己的 Agent Core、PersonaEngine 与 mcp-phone。
